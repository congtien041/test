Miễn phí & nhẹ hơn

Lưu kho ảnh không cần máy chủ trả phí

Web tĩnh không thể tự đẩy ảnh lên cloud nếu chưa có tài khoản/API riêng. Cách miễn phí, riêng tư và dễ nhất là lưu trong trình duyệt, rồi xuất file nén và mở nhanh Google Drive để bạn tải file lên tài khoản của mình.

Gợi ý: bấm Sao lưu lên Google Drive để tải file .json.gz, sau đó app sẽ mở Drive để bạn kéo file vừa tải lên.
1

Lưu hằng ngày: IndexedDB

Không đăng nhập, không server, dùng miễn phí ngay trên thiết bị hiện tại.

2

Sao lưu nhẹ: JSON nén

Nút “Xuất file nhẹ” tạo file nén nhỏ hơn JSON thường, vẫn nhập lại được trong app.

3

Cất ở Google Drive miễn phí

Bấm “Sao lưu lên Google Drive”, đăng nhập Drive rồi tải file sao lưu vừa tải xuống. Không cần máy chủ trả phí.
